# Global Garden - Water Quest

## What the project does
Global Garden is a browser-based mini game that raises awareness about global clean water access.

In the game, the player manages a small garden by:
- Planting seeds
- Watering crops over simulated day cycles
- Harvesting fully grown crops to earn score
- Clearing dead crops

The game includes:
- A world status panel that shows a simulated "population without clean water" percentage
- Difficulty settings (`easy`, `normal`, `hard`) that change crop wither risk
- A donation button that opens the charity: water website
- Milestone messages, feedback text, and demo leaderboards
- Local save/restore so progress persists between sessions using browser storage
- Debug controls to advance time, add points, refresh global percentage, and reset game

## Technologies used
- HTML for page structure and accessible UI elements
- CSS for layout, responsive styling, and visual theme
- Vanilla JavaScript for game logic, DOM interaction, state management, and persistence
- Browser Local Storage API for saving player progress
